# Changelog

## 0.2.0 — Absinthe Tower Expansion Package

- Packaged the original 100-floor Absinthe Tower source supplied by Blair Page.
- Added current rAthena YAML import files for custom items and item groups.
- Added Mini Boss Card Album and MVP Card Album usable-item scripts.
- Added Alchemical Reliquary and Sage's Stone Cache random-item systems.
- Kept dungeon monsters as the same public rAthena monster IDs; only the displayed dungeon name is changed.
- Added floor-depth + server card-rate scaling for dungeon album rolls.
- Added original MIDI placeholders/compositions for tier, boss, and victory music.
- Added client patch structure and Thor/GRF/RGZ deployment notes.
- Added AWS/Aurora deployment runbook, rollback, and validation scripts.
